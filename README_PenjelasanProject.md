# INVENTA
### Sistem Informasi Inventaris dan Peminjaman Alat Praktikum RPL

## 1. Judul Project

**INVENTA – Sistem Informasi Inventaris dan Peminjaman Alat Praktikum RPL**

## 2. Deskripsi Singkat

INVENTA merupakan aplikasi berbasis web yang dikembangkan untuk membantu pengelolaan inventaris dan peminjaman alat praktikum di jurusan Rekayasa Perangkat Lunak (RPL). Aplikasi ini dibuat untuk mengatasi permasalahan pencatatan inventaris dan peminjaman alat yang sebelumnya masih dilakukan secara manual.

Tujuan pembuatan aplikasi INVENTA adalah mempermudah pengelolaan data alat, memantau ketersediaan stok, serta mengelola proses peminjaman dan pengembalian alat. Dengan adanya aplikasi ini, proses pengelolaan inventaris diharapkan menjadi lebih terstruktur, efektif, dan efisien.

## 3. Fitur Utama

**A. Admin**
- Login Admin untuk masuk ke sistem.
- Dashboard untuk melihat ringkasan data inventaris dan peminjaman.
- Manajemen Kategori untuk mengelola kategori alat.
- Manajemen Alat untuk menambah, mengubah, dan menghapus data alat.
- Manajemen Stok untuk memantau jumlah dan kondisi alat.
- Manajemen Peminjaman untuk menyetujui atau menolak pengajuan.
- Manajemen Pengembalian untuk mengelola pengembalian alat.
- Laporan untuk melihat data inventaris dan peminjaman.

**B. Siswa/Guru (Peminjam)**
- Register untuk membuat akun baru.
- Login untuk masuk ke aplikasi.
- Dashboard untuk melihat informasi peminjaman.
- Katalog Alat untuk melihat daftar alat praktikum.
- Pencarian Alat berdasarkan nama atau kategori.
- Pengajuan Peminjaman untuk mengajukan peminjaman alat.
- Riwayat Peminjaman untuk melihat status dan riwayat transaksi.
- Informasi Pengembalian untuk mengetahui informasi pengembalian alat.

## 4. Teknologi yang Digunakan

Teknologi yang digunakan dalam pengembangan aplikasi INVENTA meliputi:

- **Laravel 11** – Framework untuk membangun aplikasi web.
- **PHP** – Bahasa pemrograman backend.
- **MySQL** – Database untuk menyimpan data aplikasi.
- **HTML** – Membuat struktur halaman web.
- **CSS** – Mengatur tampilan dan desain aplikasi.
- **JavaScript** – Menambahkan interaksi pada halaman web.
- **Tailwind CSS** – Membantu pembuatan desain antarmuka.
- **Blade Template** – Mengelola tampilan halaman pada Laravel.
